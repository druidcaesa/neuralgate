NeuralGate 接口调用说明

当前网关地址:

NeuralGate 对外同时提供 OpenAI 兼容 与 Anthropic Messages 两种协议入口,底层接入的模型是什么协议都无所谓——网关负责双向转换。下方选择你要用的入口,按示例调用即可。
调用所用的 API Key 在管理后台「API Key」页创建;示例中把 <API Key> 换成你的真实 Key。

两种协议怎么选

  • 已有 OpenAI SDK / OpenAI 兼容代码 → 用 OpenAI 兼容 入口(/v1/chat/completions)。
  • 用 Anthropic SDK / Claude 风格请求 → 用 Anthropic Messages 入口(/v1/messages)。
  • 模型名两入口共用同一套:对外 model 字段填管理后台「模型配置」里配置的模型名称(不是上游内部名)。

选择入口

端点

用途方法 / 路径
对话(含工具调用)POST {{BASE_URL}}/v1/chat/completions
可用模型列表GET {{BASE_URL}}/v1/models

鉴权

请求头 Authorization: Bearer <API Key>

非流式示例

curl {{BASE_URL}}/v1/chat/completions \
  -H "Authorization: Bearer <API Key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"my-model","messages":[{"role":"user","content":"你好"}]}'

流式示例

curl -N {{BASE_URL}}/v1/chat/completions \
  -H "Authorization: Bearer <API Key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"my-model","messages":[{"role":"user","content":"你好"}],"stream":true}'
流式按 OpenAI 约定以数据块结束,末条为 data: [DONE]。

用 OpenAI SDK 时,把 base_url 指向当前网关地址、鉴权用 sk-… 风格的 API Key 即可,路径与请求体与 OpenAI 一致。

端点

用途方法 / 路径
对话(含工具调用)POST {{BASE_URL}}/v1/messages

鉴权

请求头 x-api-key: <API Key> + anthropic-version: 2023-06-01。
也兼容 Authorization: Bearer <API Key>(两者同时带时 Bearer 优先);同一个管理后台 Key 两个入口通用。

非流式示例

curl {{BASE_URL}}/v1/messages \
  -H "x-api-key: <API Key>" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{"model":"my-model","max_tokens":1024,"messages":[{"role":"user","content":"你好"}]}'

流式示例

curl -N {{BASE_URL}}/v1/messages \
  -H "x-api-key: <API Key>" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{"model":"my-model","max_tokens":1024,"messages":[{"role":"user","content":"你好"}],"stream":true}'
max_tokens 是 Anthropic 必填字段;若请求不带,网关会按该模型在管理后台配置的「默认 max_tokens」注入。流式以 message_stop 事件结束,没有 [DONE]。

用 Anthropic SDK 时,把 base_url 指向当前网关地址、走 /v1/messages 路径即可,请求体与 Anthropic 一致。

流终止速记:[DONE](OpenAI 兼容)vs message_stop(Anthropic)。
