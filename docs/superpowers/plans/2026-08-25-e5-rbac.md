# Enterprise E5 权限体系(RBAC) 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 PRD 3.7 六项——多租户隔离、租户管理、RBAC 角色管理、用户管理、操作审计、功能权限，验收对齐 PRD 6.6。

**Architecture:** 扩展现有认证体系：tenants/roles/admin_operation_logs 三张新表 + admin_users 增量加列；权限在登录时固化进 HMAC 会话；`RequirePermission` gin 中间件守卫路由；数据面经 `core.TenantGate`(30s TTL 缓存)联动租户禁用。RBAC 以 bool 开关门控（非 BuildTag——admin/core 层 oss 版恒关即零变化）。

**Tech Stack:** Go + gin + zap + modernc.org/sqlite / mysql；webui Vue3 + element-plus。

## Global Constraints

- 所有 Go 文件带 Apache-2.0 头 `Copyright 2026 FanYaNan`；注释只写方案
- 测试双矩阵全绿：`go test -tags oss ./...` 与 `go test -race -tags enterprise ./...`

- 超管判定 = 全局角色(tenant_id="")且 permissions 覆盖 AllPermissions 全集
- 跨租户写操作返回 404（不暴露存在性）；同资源冲突返回 409
- 权限编码以 PRD 十码为准，扩展 rate_limit:read|write、privacy:read|write 两组

### 关键接线事实（探索已确认）

- `sessionClaims{Sub,Name,PwdDigest,Exp}` 需扩三字段；`Mint(user, now)` 签名变更波及 handleLogin 与 auth_test.go 全部调用点
- `AuthMiddleware(storage)` 签名不可变（NewPipeline 31 处调用）——TenantGate 在其闭包内构造，每链一份

- SQLite 加列前查 `PRAGMA table_info(admin_users)`；MySQL 查 information_schema（仿 ensureAuditColumnSizes）
- 权限常量放 **pkg/plugin**（storage 种子需要；admin 导入 plugin 方向安全，反向会循环）
- EnsureBootstrapAdmin 建账号时挂超管角色；SQL 迁移对存量账号做 `UPDATE admin_users SET role_id=... WHERE role_id=''`
